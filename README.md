# 暗棋大乱斗 · 微信小游戏

支持暗棋、经典象棋、揭棋、合棋。保留上一版大厅匹配与好友邀请恢复修复；本版更新对局动画、选中层级与 AI 分档，整理了历史参考资源。

## 导入与部署

1. 解压后，在微信开发者工具以“小游戏”导入含 `game.js`、`game.json`、`project.config.json` 的目录。
2. AppID 与云环境仍沿用原配置。确认 `config.js` 的环境属于你的项目。
3. 右键 `cloudfunctions/gameService` → **上传并部署：云端安装依赖**。只编译小游戏不会更新匹配修复及同步后的云端合棋规则。
4. 人机模式无需云函数；微信登录、匹配、好友分享需要云开发部署与平台隐私配置。

## 本次变更与验证

详见 [更新说明](docs/更新说明-20261025.md) 和 [验收步骤](docs/验收步骤.md)。

AI 目标为自身胜率：简易 30%、普通 60%、困难 80%。现已调整搜索预算和容错策略；这些数字是调优目标，尚未通过充分玩家样本验证，不代表保证胜率。

```sh
node tools/sync-server.js
```

评测工具：`node tools/evaluate-ai.js report.json 20 240`。包内 `tools/ai-reference` 保留原版评测对手。可用 `CHESS_BASELINE=/path/to/original/utils` 替换基准。固定对手是原版普通 AI，按相同种子交换红黑方。实际运行时优先固定硬件、Node 版本并保留原版 `utils`；不读取暗子秘密身份，不根据目标胜率强制改变胜负。

动画截图工具：`node tools/preview-effects.js /tmp/chess-previews`，仅本地开发需要 `@napi-rs/canvas` 与 Noto CJK 字体；小游戏运行不依赖这些工具。
