# 棋子清晰度与「吃」字延时 · 验证记录

此前已完成源码修改和预览。现按用户要求，于2026-10-26打包完整项目；本包包含本轮修改及此前的精细特效、匹配修复。

## 修改

- 「吃」字从约340ms延长为1100ms：120ms淡入、560ms完整停留、420ms淡出。接触光和碎光仍短促，不延长闪光。
- 字效改为独立视觉提示，走子事件和局面快照可正常结束。文字显示期间下一步、AI、按钮与倒计时照常工作。暂停、重开、后台和超时清理沿用现有队列机制。
- 多次快速吃子只显示最新一个中央「吃」字，避免重复叠加亮度。
- 模糊来自主Canvas曾被限制在1.5倍像素比，加上固定720px的棋子缓存被二次放大。现在正常设备按实际像素比渲染（最多3倍、360万像素）；低档设备最多2倍、180万像素。大尺寸窗口按像素预算降采样。
- 棋盘与静态棋子缓存按实际显示像素创建，缓存倍率限制在1–2倍。移动棋子和静态棋子使用匹配的清晰度；缓存画布尺寸不变时复用，不反复申请大缓冲区。
- 原棋子图片、字形、阵营色、显示尺寸、合棋标记、选中圈和布局未变。没有用换字体、重新画字或AI生成图片替换棋子。

相关源码：`src/battle-effects.js`、`src/battle-timeline.js`、`src/ui-v2.js`、`src/render-resolution.js`、`src/renderer.js`、`src/ui-process.js`。

## 验证

- 153项自动化测试通过，0失败、0跳过。
- 两个画质档、7种场景、112个实际Canvas帧无渲染错误。
- 验证长字效在走子结束后继续显示，同时局面快照已释放；混合时长的提示各自清理，不残留。
- 高清屏尺寸检查：375×812逻辑视口、3倍像素比，主Canvas为1125×2436；当前棋盘静态缓存从720px升为1260px。低档及大尺寸视口保留内存上限。
- 录制调用当前真实控制器、棋规与Canvas，使用真实时钟；展示「吃」字完整停留期间继续走下一步。
- 清晰度对比图来自修改前后的同一项目Canvas，以3倍像素比原生像素对齐；普通棋子和实际合成后的合棋棋子都进行了对比。原图片文件未修改。
- 本地微信API适配器不是微信真机。清晰度与发热、内存峰值、不同微信版本的Canvas表现仍需手机验收。
