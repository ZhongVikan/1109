# 微信小游戏 V4 · 部署与验收

这是一套微信小游戏源码，使用 Canvas 2D、JavaScript 与微信云开发。没有网页套壳，也没有国际象棋组件。核心暗子规则沿用已确认版本。

## 开发者工具导入

1. 解压项目，微信开发者工具按小游戏导入 `DarkChessMiniGame` 文件夹；目录应直接包含 game.js 和 game.json。AppID 已填写为 wx5afed2840d141da3，compileType 为 game。
2. 本地人机模式不需要云环境。首页选择简易、普通、困难；用户执红先行。
3. 真人模式需开通同一 AppID 下的云开发，`config.js` 已填写 `cloudEnv: cloud1-d8gtfz047cef44c60`。
4. 控制台创建 `chess_users`、`chess_rooms`、`chess_lobby` 三个集合。**数据库客户端读写均设为禁止**：`{"read":false,"write":false}`。房间真实暗子、历史与 OPENID 仅允许云函数访问。不要开启“所有用户可读”。
5. 云存储头像目录允许用户上传自己的文件、允许对局用户读取；禁止他人覆盖与删除。按云控制台实际安全规则配置。小游戏授权按钮会上传微信授权返回的头像，云函数通过 WX 上下文识别身份。
6. 在终端运行 `node tools/sync-server.js`，同步相同规则引擎到云函数。开发者工具右键 `cloudfunctions/gameService`，选择上传并部署（云端安装依赖）。
7. 云函数使用 `wx-server-sdk`，在云端运行数据库事务；每次落子附带房间版本号。勿把服务器的 `shared` 或数据库访问改成客户端直连。上线前锁定实际安装依赖版本。
8. 用两个真实微信帐号测试头像昵称、分享卡片入房、匹配、悔棋、断线重连及超时。当前交付已配置 AppID 与云环境 ID，但尚未连接验证，**未部署、未完成真机验证**。

## 计时与暂停细则

每手 60 秒，普通选择不重置时间；合法落子才切换。0 秒判负，不能用迟到请求续命。最后 10 秒数字变红。只有当前行棋方显示时间。

人机局使用系统时间差，切后台、打开规则或设置继续计时；悔棋/重开确认暂停，取消保留剩余时间。将军提示暂停 1.2 秒。AI 在主线程分段计算，困难搜索预算约 2.2 秒；不是职业棋力保证，需通过实际对局调参。

真人局以服务端截止时间为准，客户端每 1.2 秒同步；网络中断时服务端仍计时。双方都离线时不会持续运行云函数，下一次请求按原截止时间结算；并不延长可行棋时间。悔棋、重开、和棋由对方确认，最多暂停 15 秒，每方每手最多发起一次。超时未确认视为拒绝。重新开局和悔棋后恢复每手 60 秒。当前采用共享队列事务，适合小规模联调，大规模运营应换分区匹配服务并设置限流/监控。

## 音频和表情

BGM 是本项目生成的五声音阶轻柔拨弦音轨，操作音是生成的短木质敲击音。中文语音为合成男声，文件映射见 `assets/voices/manifest.json`。所有声音均有实际资源，不依赖游戏运行时在线 TTS。可替换成正式录制素材，保持 manifest 文件名即可。

8 张表情按原图复制，没有修改图中文字或背景；拆为 `stickersA` 与 `stickersB` 按需加载，只有真人房间加载/显示。语音文字严格使用原上传文件名（不含 .png），例如“崩住！”、“卧槽上将”。真人发送由服务端白名单校验，两次发送至少间隔 2.5 秒；双方显示 3 秒。主静音会关闭表情语音。

音频设置：全部声音、背景音乐、操作音效、中文语音四个开关。音乐音量 0.16、操作音 0.7、语音 1.0。平台可能要求首次用户操作才允许播放背景音乐，须真机验收。

## 杀法识别边界

胜负裁定先于杀法命名，名称不改变规则。已实现保守形态识别：重炮、马后炮、闷杀、闷宫、闷罐杀、小鬼坐龙庭、卧槽马、挂角马、大刀剜心、白脸将、铁门栓、双车错；另有困毙、神之一手、将死、超时判负。

八角马、海底捞月、大胆穿心、二路夹车炮、高钓马、送佛归殿的语音已经准备，但**尚无可靠的自动识别器**。这些常需完整战术过程，或与别名重叠；本版统一回退“将死”，不随意播报。形态检测仍需用策划提供的标准棋谱扩大覆盖测试，不能视为全杀法识别完成。

## 本次架构迁移核验

接口签名对照微信团队发布的 `minigame-api-typings` 3.8.21（npm，仓库 https://github.com/wechat-miniprogram/minigame-api-typings）。已核对 createCanvas、createImage、getWindowInfo、createUserInfoButton、showModal、showActionSheet、loadSubpackage、onWindowResize。真机仍需验证实际基础库能力与头像下载域名。

主包入口只有 game.js，子包入口为 stickersA/game.js、stickersB/game.js；无 App()/Page() 运行依赖。服务端规则仍由 tools/sync-server.js 同步。云存储头像下载和上传须按小游戏后台实际域名及权限配置。

小游戏测试优先：导入目录/AppID → 启动首页 → 三档AI → 90点触控和翻转 → 音效 → 前后台60秒 → 云部署 → 双机授权/邀请/匹配。Canvas快照为开发环境生成，不能替代这条真机验收流程。
