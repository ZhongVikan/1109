# 头像昵称按钮隐私授权顺序修复

此说明替代 20260907 文档中“进入身份页即调用隐私授权”的描述。

进入身份页只显示按钮。点击“点击授权头像昵称”后：

1. 检查 wx.requirePrivacyAuthorize 能力与 SDKVersion，最低基础库 2.32.3。
2. 首先调用 wx.requirePrivacyAuthorize，使用微信平台隐私弹窗。
3. 用户拒绝或接口失败时停止，不读取头像昵称、不继续创建用户信息授权按钮。
4. 隐私授权成功后查询 scope.userInfo：已有授权才调用 wx.getUserInfo；首次授权则显示原生“继续授权头像昵称并登录”按钮，需要用户再点一次。
5. 成功获取真实头像昵称后沿用现有上传头像与云端保存流程。

隐私授权和头像昵称授权为两个权限步骤，不能以同意隐私指引代替头像昵称授权。返回后不再使用该次结果；忙碌期间防止重复提交。

此更改不新增云函数变动。若还没有部署上一版的更多菜单暂停，请仍按上一版说明部署 gameService。公众号后台的用户隐私保护指引及相关接口权限也仍须管理员配置；客户端流程修复不能授予 AppID 尚未获得的平台权限。

62 项自动测试通过，新增按钮点击触发、隐私授权先于 getUserInfo、拒绝中断、首次头像授权和低版本拦截测试。尚未进行微信真机登录验证。
